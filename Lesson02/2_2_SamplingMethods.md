## Lesson
Since we cannot measure the full population, we take a sample to represent the population.

There are a number ways that we can collect data from good, random samples. We will highlight a few here:

| Sampling Method | How it works | Example |
| :--- | :--- | :--- |
| Simple Random Sample | Purely random selection | Drawing names out of a hat |
| Systematic Sample	| Use a pattern for selection | People randomly line up to enter an event. Starting at the 42nd participant, sample every 7th person |
| Stratified Sample | Separate participants into groups, then select a percentage from each group | Divide students by age group (K-5th, 6th-8th, 9th-12th), then randomly select 5% of each age group |
| Cluster Sampling | Separate participants into groups, then randomly select everyone from a percentage of the groups | Looking at all MATH 1040 sections across the state of Utah, randomly select one section from each school and test all students in that section |

These methods, if done appropriately, will eliminate bias as it gives everyone an equal opportunity of being selected.
