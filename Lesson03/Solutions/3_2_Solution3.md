## 3.2 Experimental Studies - Solution for Practice 3
A school district wants to test whether a new reading curriculum improves student test scores. They select 6 elementary schools and randomly assign 3 schools to use the new curriculum and 3 schools to use the existing curriculum. At the end of the year, they compare average reading scores across the two groups.

### Solution
There are many ways to establish a study that will answer this question. Below is one possible solution.
- __Treatment__: The new reading curriculum
- __Control Group__: The 3 schools using the existing (standard) curriculum
- __Treatment Group__: The 3 schools using the new curriculum
- __Explanatory Variable__: Which reading curriculum is used (new vs. existing)
- __Response Variable__: Average student reading test scores at the end of the year
