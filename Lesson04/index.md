## Lesson 4 Graphing
We have learned in the first three lessons how to sample a population and collect data. Once we have the data, we need to understand what the data tells us. In a way, statistics is a process of storytelling, exploring the stories told by the data. We can explore data in two ways: __graphically__ and __numerically__. Lessons 4 and 5 will focus on graphing. We'll explore the calculations in units 2 and 3.

Graphing is when we display the data in a visual format, which gives a visual understanding to the data. __The most effective graphs are the ones that take little or no explanation for the reader to understand.__ So, when making a graph, we need to make sure it is as clear and possible. In this lesson, we will look at the different types of graphs and how to read them. These graphs will display both quantitative and categorical data. Here are some of the graphs we'll look at:

| Quantitative Graphs             | Categorical Graphs   |
| :-----------------------------: | :------------------: |
| Dotplot                         | Bar graph            |
| Stem-and-leaf plot              | (Paretto chart)      |
| Scatterplot                     | Pie chart            |
| Timeseries                      |                      |
| Histogram (Lesson 5)            | Histogram (Lesson 5) |
| Box-and-whisker plot (Lesson 6) |                      |

We'll also look at how to effectively make these graphs.

## Lesson Objectives
By the end of this lesson, you should be able to accomplish the following:
- Choose an appropriate type of graph based on whether the data is categorical or quantitative
- Construct a bar graph, Pareto chart, and pie chart from categorical data
- Construct a dotplot, stem-and-leaf plot, scatterplot, and time series graph from quantitative data
- Read and interpret each type of graph, including identifying patterns, trends, and unusual features
- Identify the explanatory and response variables in a scatterplot or time series graph
