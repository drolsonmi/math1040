## 5.2 Creating a Histogram - Solution for Practice 2

2. A teacher has already grouped her 35 students' exam scores into the frequency table below. Use this table to draw a histogram.

| Exam Score | Frequency |
| ---------- | --------- |
| 50 - 60    | 3         |
| 60 - 70    | 7         |
| 70 - 80    | 12        |
| 80 - 90    | 9         |
| 90 - 100   | 4         |

### Solution

Since the bins are already given to us, we can skip straight to Steps 5 and 6: create a proper scale on the x-axis using the bin boundaries (50, 60, 70, 80, 90, 100), a proper scale on the y-axis reaching at least up to 12, and draw a bar for each bin with **no gaps** between them.

As a check, the frequencies should add up to our sample size: $3 + 7 + 12 + 9 + 4 = 35$. ✓
