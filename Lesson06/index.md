## Lesson 6 Measures of Center
 
Graphs are a great way to get a visual sense of a dataset, but they don't give us anything we can put a number to. If someone asks "what's a typical value in this dataset?" or "how spread out is this data?", we need something more precise than a picture — we need to calculate it.
 
In this lesson, we'll look at three **measures of center**: the **mean**, the **mode**, and the **median**. Each one tries to answer the question "where is the middle of this data?", but each does it differently, and each has situations where it works well and situations where it can be misleading — especially when outliers are involved.
 
We'll then extend the idea of the median to **quartiles**, which split a dataset into four equal parts. Together with the minimum and maximum, the quartiles make up the **5-number summary**, which is one of the most useful ways to describe a quantitative dataset. Finally, we'll use the 5-number summary to construct a **box-and-whisker plot (boxplot)**, a graph that displays the spread, center, and any outliers in a dataset all at once.
 
## Lesson Objectives
 
By the end of this lesson, you should be able to accomplish the following:
 
- Calculate the mean, median, and mode of a dataset, both by hand and using technology
- Explain how outliers affect the mean, median, and mode differently, and choose the most appropriate measure of center for a given dataset
- Calculate the 5-number summary (minimum, Q1, median, Q3, maximum) of a dataset
- Calculate the interquartile range (IQR) and use it to identify outliers
- Construct a box-and-whisker plot from a 5-number summary
- Use a boxplot to describe the center, spread, and shape of a distribution, and to compare two or more datasets
