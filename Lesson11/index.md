# Lesson 11: Rules of Counting
In lessons 9 and 10, we have learned about basic probability calculations. These by themselves will help with doing calculations of Categorical variables. However, __probability theory__ expands what we have learned to get more sophisticated calculations. We’ll introduce some of the concepts of probability theory by looking at Probability Distributions (Lesson 12) and Binomial Distributions (Lessons 13 and 14).

In order to understand these, we need to talk about the __rules of counting__. These are just a few probability tools that we will need for lessons 12-14.

## Outcomes
By the end of this lesson, you should be able to accomplish the following:

- Apply the Fundamental Counting Rule to find the total number of possible outcomes when multiple events occur together
- Calculate a factorial and recognize when a counting problem calls for one
- Calculate the number of permutations of a set, and explain when order matters in a counting problem
- Calculate the number of combinations of a set, and explain how combinations differ from permutations
- Choose the correct counting technique (Fundamental Counting Rule, factorial, permutation, or combination) for a given real-world scenario
