# Lesson 12: Probability Distributions

When learning about Histograms in Lesson 5, we saw that the shape of the graph can look different. We saw that graphs can be normal, skewed left, skewed right, or uniform. These shapes are known as __distributions__.

Your textbook defines a distribution as a representation of "the values that a variable takes and the frequency of these values." In other words, it shows the patterns made by the data. 

When looking at a distribution, we're really asking two things: what values can this variable take, and how likely is each of those values to occur? Once we can answer those two questions, we have everything we need to describe, compare, and eventually calculate things about almost any random process.

## Lesson Objectives
 
By the end of this lesson, you should be able to accomplish the following:
 
- Determine whether a table of values represents a valid probability distribution
- Identify and describe common distribution shapes, including uniform, normal, skewed left, skewed right, and binomial
- Calculate the expected value of a discrete probability distribution
- Interpret the expected value as the long-run average outcome of a random variable
