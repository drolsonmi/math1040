## Lesson 13 Binomial Distributions
In [lesson 12](../Lesson12/index.html), we learned how to build a probability distribution for a discrete random variable and how to find its expected value. In lesson 13, we will focus on one very common and very useful type of discrete distribution: the __binomial distribution__.

A binomial distribution shows up any time we repeat the same yes/no trial over and over — flipping a coin, checking whether a part is defective, asking whether a voter supports a candidate — and we want to know the probability of getting a certain number of "successes." We will learn how to recognize a binomial setting, how to calculate the probability of an exact number of successes, and how to build the full binomial probability distribution.

## Lesson Objectives

By the end of this lesson, you should be able to accomplish the following:

- Identify whether a given scenario is a binomial experiment, and describe it using $n$, $p$, $q$, and $r$
- Calculate the probability of exactly $r$ successes in a binomial experiment, by hand and with technology
- Construct the full binomial probability distribution for a given $n$ and $p$
