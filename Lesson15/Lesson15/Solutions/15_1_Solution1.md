## 15.1 Discrete and Continuous Distributions - Solution for Practice 1
1. The number of siblings a randomly selected student has.

### Solution

This variable is **discrete**. The number of siblings a student has must be a whole number — 0, 1, 2, 3, and so on. It is not possible to have 2.5 siblings, so the possible values form a countable list rather than a continuous range.
