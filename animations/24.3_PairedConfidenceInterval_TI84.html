Paired-data confidence interval: TI-84

MATH 1040, Lesson 24.3

Example

Did the typing course help?

A college offers a two-week keyboarding course. Nine randomly selected students had their typing speed measured before and after the course.

Construct a 95% confidence interval for the mean improvement in typing speed, \(\mu_d\). Assume the population of differences is normally distributed.

We need that assumption for the CLT check, because the sample is small. The same students are measured twice, so the samples are dependent (paired).

Move through the lesson with Next and Back, or the ← → keys.

On the TI-84 · Step 1

Enter the data

Open the list editor and type each list, pressing ENTER after every value.

  1. Press STAT, then ENTER for 1:Edit.
  2. Type the After speeds (\(x_1\)) into L1.
  3. Press ▶ and type the Before speeds (\(x_2\)) into L2.
Old data in a list? Arrow up to the list name (L1), press CLEAR, then ENTER.

On the TI-84 · Step 2

Let the calculator find the differences

Put a formula in the name of L3, and the calculator fills the whole list at once.

  1. Press ▶ to move to L3, then ▲ to highlight the name L3.
  2. Type 2ND 1 (L1), −, 2ND 2 (L2).
  3. Press ENTER.

L3 now holds \(d = x_1 - x_2\): 6, 3, 7, 2, 3, 7, 2, 6, −1.

On the TI-84 · Step 3

Check the requirements

Use a box plot of the differences in L3 to check the shape.

  • Paired samples. Each After value has exactly one Before value from the same student.
  • Random sample. The students (pairs) were randomly selected.
  • Normal differences or n ≥ 30. Since \(n = 9\), the sample size is not large enough. However, the problem stated we can assume the population is normal. The box plot shows no outliers or strong skew, showing it is normal. So, we can go on.

There are no outliers: the whiskers run from −1 to 7.

On the TI-84 · Step 4

Open TInterval

Paired data become one sample of differences, so we use the one-sample t interval.

  1. Press STAT, then ▶ ▶ to the TESTS menu.
  2. Arrow down to 8:TInterval (or just press 8).
  3. Press ENTER.
Don’t choose 2-SampTInt. That is for independent samples.

On the TI-84 · Step 5

Fill in the settings

  • Inpt: Data, because we have the raw values in a list.
  • List: L3, the differences. Type it with 2ND 3.
  • Freq: 1, each value counts once.
  • C-Level: .95 for 95% confidence.
  • Arrow down to Calculate, pause to check every setting, then press ENTER.

On the TI-84 · Step 6

Read the output

The first line after the title is the interval.

What each line of the output means
ScreenMeaning
(1.7683,6.0095)the confidence interval
x̄=3.888888889\(\bar{x}_d\), mean of the differences
Sx=2.758824226\(s_d\), standard deviation of the differences
n=9number of pairs
\[ 1.77 < \mu_d < 6.01 \]

Rounded to two decimal places. It matches the by-hand answer.

Interpret

What the interval tells us

We are 95% confident that the true mean improvement in typing speed is between 1.77 and 6.01 words per minute.

The entire interval is above 0, so there is evidence that \(\mu_d > 0\): the course increases typing speed, on average.

The calculator does the arithmetic, but you still write the interpretation in context.

Summary

Keystrokes at a glance

  1. STAT ENTER: enter \(x_1\) in L1 and \(x_2\) in L2.
  2. Highlight the name L3, type L1 − L2, ENTER.
  3. STAT ▶ ▶ 8:TInterval.
  4. Data, List: L3, Freq: 1, C-Level, Calculate.
  5. Round, then interpret in context.
